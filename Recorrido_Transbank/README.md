# Procesador de Gestiones · Transbank

Aplicacion web cliente (100% local en navegador) para procesar bases de Transbank con el informe de llamadas.

## Como ejecutar
- Doble clic en iniciar_transbank.bat en la raiz del proyecto, o
- Abrir directamente transbank-extractor/index.html en el navegador.

## Estructura
- index.html: Estructura web.
- styles.css: Estilos visuales.
- app.js: Logica de cruce y exportacion.
- vendor/: Librerias locales (xlsx.full.min.js, jszip.min.js).
