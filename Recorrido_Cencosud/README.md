# Newlead Contact Center · Procesador de Recorridos Cencosud

Aplicación de escritorio nativa para Windows (100% offline y sin dependencias de servidor) diseñada para la homologación oficial de recorridos de campañas Cencosud.

## 🚀 Inicio Rápido
- **Ejecutable Directo:** Haz doble clic en Newlead-Cencosud.exe.
- **Script de Inicio:** O ejecuta iniciar_cencosud.bat.
- **Acceso Directo:** Ejecuta crear_acceso_directo.bat para añadir el acceso al Escritorio.
