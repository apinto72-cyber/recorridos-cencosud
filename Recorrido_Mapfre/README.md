# Procesador de Gestiones · Mapfre

Aplicación de escritorio cliente (100% local en navegador / ventana de aplicación Windows) para procesar bases de Mapfre con el informe de llamadas outbound.

## Cómo ejecutar
- Doble clic en `iniciar_mapfre.bat` en la raíz del proyecto, o
- Ejecutar directamente `Newlead-Mapfre.exe`, o
- Abrir `Recorrido_Mapfre/index.html` en el navegador.

## Accesos directos y compilación
- `crear_acceso_directo.bat`: Genera un acceso directo en el Escritorio con icono corporativo.
- `compilar_ejecutable.bat`: Recompila `Newlead-Mapfre.exe` integrando cualquier cambio en código HTML/JS/CSS.
